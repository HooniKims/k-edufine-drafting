# K-에듀파인 공문 기안 스킬

프로젝트 폴더의 자료를 읽고 서울교육 업무포털에 접속하여, K-에듀파인의 별도 기안 프로그램에 공문을 입력하는 **Codex용 스킬**입니다.

## 필요한 환경

- Windows PC와 Codex 데스크톱 앱
- Codex에 연결된 브라우저(기본 추천: Chrome)
- Windows 앱을 조작하는 **Computer Use 플러그인**
- 서울교육 업무포털에 접속할 수 있는 환경과 본인의 인증서
- 해당 PC에서 정상 동작하는 K-에듀파인 기안 프로그램

스킬은 작업 순서를 안내합니다. 플러그인·브라우저 연결·인증 프로그램을 자동 설치하는 실행 프로그램은 아닙니다. 로컬 HWP/HWPX·PDF·DOCX 등의 자료를 읽을 수 있는 관련 스킬도 필요합니다.

## 설치

### 방법 1: Codex에 설치 요청

이 저장소 주소를 전달하여 요청합니다.

```text
https://github.com/HooniKims/k-edufine-drafting 의 스킬을 설치해줘.
저장소 루트의 SKILL.md와 agents, references 폴더를 함께 설치해줘.
```

### 방법 2: 직접 설치

1. 이 저장소의 **Code → Download ZIP**을 선택합니다.
2. 압축을 풀고 폴더 이름을 `k-edufine-drafting`으로 맞춥니다.
3. 폴더 전체를 `%USERPROFILE%\.codex\skills\` 아래에 복사합니다. 별도 `CODEX_HOME`을 사용하는 경우 그 아래의 `skills` 폴더에 설치합니다.
4. Codex의 새 작업에서 스킬을 불러봅니다. 목록에 나타나지 않으면 앱을 다시 열어 확인합니다.

설치 결과는 다음 구조여야 합니다. 압축을 풀면서 폴더가 이중으로 들어가지 않도록 확인하세요.

```text
.codex/
└─ skills/
   └─ k-edufine-drafting/
      ├─ SKILL.md
      ├─ agents/
      │  └─ openai.yaml
      └─ references/
         ├─ intake.md
         ├─ document-format.md
         ├─ ui-workflow.md
         └─ user-defaults.md
```

업데이트할 때는 개인적으로 수정한 내용을 먼저 백업하고 같은 폴더의 파일을 최신 버전으로 교체합니다.

## 사용 방법

### 1. 자료 준비

Codex 프로젝트 폴더에 기안의 근거 자료와 첨부할 파일을 넣습니다. 계획서, 안내문, 관련 공문 등의 최종본을 사용하고, 요청할 때 대상 파일을 지정하면 더 정확합니다.

### 2. 스킬 호출

```text
$k-edufine-drafting 이 프로젝트의 계획서와 안내문으로 협의회 운영 공문을 기안해줘.
추천안을 먼저 제시하고, 입력과 화면 검토까지만 진행해줘.
```

샘플로 시험하려면 다음처럼 요청합니다.

```text
$k-edufine-drafting 실제 상신 없이 샘플 기안문을 작성해줘.
첨부는 개인정보 없는 테스트 파일로 만들고 입력 결과를 확인해줘.
```

### 3. 로그인

스킬은 `https://sen.eduptl.kr` 접속과 로그인 상태를 먼저 확인합니다. 이미 로그인되어 있으면 기존 세션을 사용합니다.

로그인이 필요하면 직접 로그인과 자동 로그인을 선택하도록 묻습니다. 자동 로그인에 동의한 경우에만 이번 로그인에 사용할 인증서 비밀번호를 요청합니다. 사용 가능한 도구에서 인증 창 조작이 제한되거나 추가 인증이 필요하면 해당 단계는 직접 처리합니다.

비밀번호를 이 저장소, 프로젝트 파일, GitHub 이슈에 기록하지 마세요. 대화로 제공하면 대화 기록에 남을 수 있습니다. **자동 로그인 절차는 작성되어 있으나 실제 로그인 성공 시험은 아직 하지 않았습니다.**

### 4. 추천안 확인

자료를 읽은 뒤 제목·과제카드·관련 근거·일정·예산·첨부 등에 대해 추천안을 제시합니다. 자료가 서로 다르거나 필수 정보가 없을 때 질문하며, 이미 답한 사항은 다시 묻지 않습니다.

결재선은 **담당 부장 → 교감 → 교장**을 기본으로 추천하고, 행정실장 협조와 공람 대상을 함께 묻습니다. 개인 이름은 고정하지 않으며 현재 조직도로 확인합니다.

```text
결재는 기본대로 하고, 행정실장 협조를 교감 앞에 추가해줘.
공람은 연구부 교원으로 지정해줘.
```

### 5. 실제 기안 입력과 확인

브라우저에서 **K-에듀파인 → 문서관리 → 기안 → 공용서식 → 일반기안문**으로 이동합니다. 이후 별도 Windows 기안 프로그램을 Computer Use로 조작합니다.

기본 동작:

- 키워드는 생성하거나 입력하지 않습니다.
- 문서 공개구분은 **비공개·6호**를 적용합니다. 사용자 운영 기본값이며, 모든 문서에 대한 법적 적합성 판단을 뜻하지 않습니다. 다른 기준이 필요하면 요청에 명시하세요.
- 붙임 위에 빈 줄 한 줄을 둡니다.
- 붙임 1개는 번호 없이, 2개 이상은 번호를 매깁니다.
- 붙임 항목의 종결 마침표는 마지막 항목에만 둡니다.
- 기본 완료는 **입력과 화면 검토까지**입니다. 임시저장·결재올림·발송은 별도 요청 없이는 실행하지 않습니다. 프로그램 자체의 자동저장이 있을 수 있습니다.

## 적용 범위와 확인 상태

서울교육 업무포털과 Windows K-에듀파인 일반기안문 환경을 기준으로 만들었습니다. 교육청·기관·프로그램 버전에 따라 메뉴와 동작이 다를 수 있습니다. 교육청이나 K-에듀파인의 공식 배포물이 아닙니다.

- 실제 샘플에서 확인: 브라우저 진입, 별도 기안창 선택, 제목·과제카드·요지·본문 입력, 결재선 지정, 파일 첨부, 키워드 비우기, 비공개·6호 선택
- 가상 사례로 확인: 자료 충돌 질문, 행정실장 협조·공람 구분, 붙임 개수별 양식
- 실제 실행 미검증: 자동 인증서 로그인, 행정실장 협조·공람 지정, 임시저장·결재올림·발송
