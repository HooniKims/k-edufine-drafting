# 사용자 기본값

- 포털: 서울교육 업무포털 `https://sen.eduptl.kr`.
- 지정이 없을 때 연결된 Chrome 우선. 브라우저 지정이 있으면 그 요청 우선.
- 서식: 일반기안문 서식(결재4인,협조4인).
- 완료: 입력·화면 검토까지. 임시저장·결재올림은 별도 요청 시(사용자 명시 확인).

## 결재선과 공람 질문

개인 이름은 고정 저장하지 않는다. 기본 역할 순서만 **담당 부장 → 교감 → 교장**으로 추천한다. 현재 문서에 필요한 부장을 선택하며 교무부장으로 일률 고정하지 않는다.

한 번에 묻기: “부장(검토) → 교감(검토) → 교장(결재)로 할까요? 행정실장 협조나 공람 대상이 있으면 함께 알려주세요.”

- 이미 이번 요청에 경로가 명시돼 있으면 아는 것을 반복 질문하지 않는다.
- “기본대로”이면 기본 세 역할, 행정실장 추가 없음, 공람 없음으로 처리한다.
- 행정실장이 필요하면 참여 위치·검토/협조 등 처리방법을 문서 성격에 맞춰 추천한다. 명시된 지시는 그대로 따른다.
- 공람은 결재선과 별도 목록이다. 대상·범위가 모호할 때만 최소 추가 질문으로 확정한다.
- 역할에 해당하는 사람은 현재 조직도에서 확인한다. 여러 후보라 구분할 수 없을 때만 이름을 묻는다.
- 개별 역할마다 ‘맞나요’를 반복하지 않는다. 최종 검토에서 전체 경로와 공람을 함께 요약한다.

- 최초 로그인 필요 시 직접/자동 선택 질문. 자동 동의 후 비밀번호 요청·현재 포털 로그인에만 사용. 이미 로그인된 세션은 재사용. 비밀번호 영구 저장 없음.

## 결재정보 기본값

- 키워드는 생성하거나 입력하지 않는다. 새 문서 키워드 칸은 비워 둔다.
- 문서 공개구분은 비공개, 공개제한근거는 6호를 기본 적용한다. 이미 지정된 기본값을 매번 묻지 않는다. 사용자가 다른 기준을 명시하면 우선한다.
- 사용자 운영 기본값으로 적용하며 모든 문서에 6호가 법적으로 적용된다고 주장하지 않는다. 실제 사유 문구는 지어내지 않는다.
