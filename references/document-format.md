# 사용자 공문 양식

사용자가 직접 수정한 화면과 지시를 기준으로 한다. 기관의 새 양식/사용자 명시 지시가 우선한다. 법령상 보편 규칙이라고 확대하지 않는다.

## 본문

- 관련 근거가 있으면 `1. 관련: 발신기관-문서번호(시행일)`로 시작한다. 실제 번호·날짜만 사용한다. 없으면 생략을 추천하고 나머지 번호를 조정한다.
- 큰 항목은 `1.`, `2.`, `3.`으로 왼쪽 기준선을 맞추고 번호 뒤 한 칸을 둔다.
- 하위 항목은 `가.`, `나.`, `다.` 순으로 두 칸 들여쓰기를 기본 추천한다. 표시 뒤 한 칸을 둔다. 새 큰 항목에서는 다시 `가.`부터 시작한다.
- `일시: 내용`, `장소: 내용`처럼 콜론 다음 한 칸. 각 항목은 새 문단/새 줄. 큰 항목 사이에 일률적으로 빈 줄을 넣지 않는다.
- 본문 일시는 화면 예시처럼 `2026. 9. 23.(수) 15:30~16:00`로 연·월 뒤 점과 공백, 일 뒤 점을 둔다. 요일은 실제 날짜와 대조하며, 종료 시간이 자료에 없으면 만들어 넣지 않는다. 관련 근거의 문서번호와 날짜는 원문 표기를 우선한다.
- 추가 단계가 필요하면 실제 참고 문서와 대조한다. 화면에서 확인하지 않은 기관 고유 규칙을 만들어 고정하지 않는다.
- 자동 제목·기관명·수신/결재란을 유지하고 본문 필드만 채운다. 글꼴·크기·줄 간격은 기존 서식을 우선 유지한다.
- 화면으로 정확히 판별할 수 없는 공백 문자 수/문단 속성을 확정 규격이라고 단정하지 않는다. 줄넘김과 들여쓰기는 입력 뒤 화면으로 대조한다.

## 붙임

1. 본문 마지막 문단과 붙임 첫 줄 사이에 **빈 줄 정확히 한 줄**.
2. 한 개이면 번호 없음. 두 개 이상이면 `1.`, `2.` 번호 부여.
3. **붙임 항목의 종결 마침표는 마지막 항목에만**. 항목 번호의 점이나 확장자 점은 별개다.
4. `붙임` 뒤 두 칸, 마지막 항목 뒤 두 칸과 `끝.`을 기본으로 한다.
5. 두 번째 붙임 이하 번호 시작점은 첫 번째 번호와 정렬한다. 비례 글꼴에서는 공백 개수만 세지 말고 화면을 본다.
6. 붙임이 없으면 붙임 줄을 만들지 않고 본문 말미에 두 칸 뒤 `끝.`을 쓴다.

### 한 개

```text
1. 관련: 실제 근거 문서번호(시행일)
2. 협의회를 다음과 같이 운영하고자 합니다.
  가. 일시: 확인된 일시
  나. 장소: 확인된 장소

붙임  협의회 운영계획 1부.  끝.
```

### 두 개 이상

```text
1. 관련: 실제 근거 문서번호(시행일)
2. 협의회를 다음과 같이 운영하고자 합니다.
  가. 일시: 확인된 일시
  나. 장소: 확인된 장소

붙임  1. 협의회 운영계획 1부
      2. 안내자료 1부.  끝.
```

구조 예시의 ‘확인된 일시’ 등을 실제 값처럼 입력하지 않는다. 붙임 제목은 실제 첨부와 대응되도록 제시한다.

## 빈 줄 검증과 보정

여러 줄 입력은 작동했지만 연속 줄바꿈이 기대한 빈 문단으로 남지 않은 사례가 있었다. 문자열에 `\n\n`이 있다는 것만으로 성공 처리하지 않는다.

- 화면에서 본문 마지막 항목과 붙임 사이 빈 줄을 확인한다.
- 없으면 편집 영역의 붙임 첫 줄 맨 앞에 커서를 놓고 위치를 확인한 뒤 별도 키 입력 `Return` 한 번으로 빈 문단을 만든다. 다시 확인한다.
- 두 줄 이상이면 정확한 커서 위치를 확인한 뒤 초과 문단만 제거한다. 전체 선택/삭제는 금지한다.
- 문서가 길면 본문 위아래를 스크롤하며 제목 아래 시작과 붙임 말미까지 확인한다.
